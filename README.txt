1. Umieść pliki w katalogu XAMPP: htdocs/przewozy
- przewozy.php
- styles.css
- przewozy.sql
- kwerendy.txt
- auto.png (przygotuj grafikę zgodnie z opisem: przezroczyste tło, szerokość 400px)
- napisy.jpg (jeśli chcesz nałożyć napisy w edytorze graficznym)


2. Uruchom serwer MySQL i Apache w XAMPP.
3. Zaimportuj plik przewozy.sql używając phpMyAdmin lub mysql CLI.
4. Otwórz w przeglądarce: http://localhost/przewozy/przewozy.php


Uwaga: stopka zawiera numer zdającego (zastąp 0000000000 prawidłowym numerem). Plik styles.css zawiera selektory opisane w poleceniu (selektory elementów: body, table, a, ul). Skrypt PHP używa bezpiecznych zapytań przygotowanych (prepared statements) do wstawiania i usuwania.
